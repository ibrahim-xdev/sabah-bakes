Drop your photos into this folder using these exact file names.
Until a file exists, the site shows a neat placeholder automatically —
nothing else needs to change.

  hero-cake.jpg              Hero photo, top of homepage   (square-ish, e.g. 1000x1050)
  about-baker.jpg            About section photo            (portrait, e.g. 900x1200)

  menu-jiggly-cheesecake.jpg Menu card                       (landscape, e.g. 1000x800)
  menu-buttercream-cake.jpg  Menu card                       (landscape, e.g. 1000x800)
  menu-basketball-cake.jpg   Menu card                       (landscape, e.g. 1000x800)
  menu-wedding-cake.jpg      Menu card                       (landscape, e.g. 1000x800)

  gallery-01.jpg .. gallery-07.jpg      Gallery grid photos
  gallery-video-01.jpg                  Gallery grid "video" thumbnail

Want to add more menu items or gallery photos? Just add new entries to the
`menu` or `gallery` arrays in /js/data.js with a new file name — the page
builds itself from that list, so you don't need to touch the HTML.
